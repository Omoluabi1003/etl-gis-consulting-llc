# ETL GIS Consulting LLC — engraved identity

The approved identity is a lifelike circular medallion: brushed metal, engraved company name, brass geographic relief, teal oceans and contour lines. The source artwork and cutout are raster images, not vector files or a fabrication-ready engraving model.

## Assets

- `etl-gis-approved-master.png`: the exact original artwork approved in the conversation, preserved unchanged.
- `etl-gis-crest.png`: high-resolution transparent placement version (1024 × 1024).
- `etl-gis-crest-128.webp` / `etl-gis-crest-256.webp`: optimized transparent header/footer marks (1× / 2× for a 64 px placement).
- `icon-16.png`, `icon-32.png`, `icon-48.png`: browser icon exports.
- `favicon.ico`: a container with all three browser sizes.
- `icon-180.png`: Apple touch icon.
- `icon-192.png`, `icon-512.png`: app/shortcut icon exports.
- `etl-gis-share.jpg`: 1200 × 630 link-sharing card with the crest and company name.

The cutout and sharing composition were prepared using image generation with the approved image as reference. The web-size variants are format/size exports of that artwork; no further logo redesign was introduced. The original source remains available above for comparison.

Keep the mark's proportions, material colors and breathing room. Use a text company name alongside small header placements, since the engraved lettering cannot be read at favicon sizes. Decorative marks next to a visible wordmark use empty alt text; standalone logo placements have a company-name alternative.

The historical `assets/images/C4376F7C-6E7F-470B-A331-84B0E39C59A7.png`, `favicon.svg` and `og-cover.svg` paths now display the approved identity as compatibility assets. Current HTML uses the new named files so new shares and browser icons request the updated artwork. Social networks may retain earlier page/image caches until they refresh or a sharing debugger requests a new scrape.
